# 内容底线不随开源模式移除

## 背景

讨论中出现“既然放开了，就不写红线、支持最大操作”的想法。
但开源、自部署并不免除法律与平台责任：未成年人性化内容在几乎所有司法辖区违法，
GitHub 也会因违规内容下架仓库。

## 决定

保留以下**不可关闭**的底线，其余成年人自愿内容尽量放开：

- 任何未成年人的性化内容（人设年龄强制 ≥18）；
- 非自愿、强迫、性暴力；
- 乱伦、兽交；
- 对真实人物的色情描写；
- 制毒、制爆、杀人等具体违法方法；
- 鼓励或指导自伤。

允许：成年人之间自愿的亲密、调情、性角色扮演；不额外说教、不切成客服腔。

部署者只能**加严**（例如关闭成人模式），不能移除底线。

## 理由

这是法律与平台规则的硬约束，不是产品保守。去掉底线会让仓库被下架、部署者承担刑责，
也会让项目失去长期存在的可能。

## 后果

- 成人模式默认关闭，需显式开启并确认 18+；
- 提示词与关键词两层都要有约束；
- 开源协议与 README 必须写清责任边界。
