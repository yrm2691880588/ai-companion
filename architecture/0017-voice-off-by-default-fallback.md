# 语音默认关闭，失败退回文字

## 背景

语音在公共场合是打扰，成本也比文字高一个量级；而链路中任何一环（录音、识别、
合成、播放）都可能失败。

## 决定

- 语音模式**默认关闭**，用户点麦克风进入，退出即回到文字；
- 识别失败：提示重说，不写入消息；
- 合成失败：**退回文字回复**，并给一行轻提示，对话不中断；
- 播放失败：保留文字，不重试音频。

## 理由

保证“对话永远不因为语音故障而断掉”，是陪伴产品的基本盘。

## 后果

- 需要区分“实时错误”（提示重说）与“降级错误”（静默退回文字）；
- 会话里可能出现“这条没有语音”的情况，前端要能表达；
- 语音成本与失败率需要埋点观察。
