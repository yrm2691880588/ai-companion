# 多端与同步另立规划，本期不做；产品不收费

## 背景

用户提出长期方向：Windows 桌面端 + Android + iOS，扫码配对、双端数据互通、
按最新进度同步；同时确认开源项目不收费。

这已经超出单个 spec 的范围：它涉及三套客户端、配对协议、同步模型、冲突解决、
应用商店合规，任何一项都足以独立规划。

## 决定

- 本期 spec（0001）**不包含**多端客户端、扫码配对、跨端同步、付费；
- 多端与同步作为**独立后续计划**，用 `wayfinder` 拆决策票，再逐项落地；
- 产品**不收费**：不做订阅、内购、额度付费；开源免费；
- 本期仍是本地单用户桌面版（Web + 本地启动器），先把体验打磨好。

## 理由

同步的难点不在“传数据”，而在冲突解决与身份配对；三端同时开工会让本期无法交付。
先把单机体验验证成立，再决定同步架构，顺序不能反。

## 后果

- 本期不做任何同步相关表结构与接口，避免为未定方案付迁移成本；
- 未来若做同步，需要重新评估会话/消息的冲突模型，不能假设“最后写入胜出”够用；
- iOS 上架与成人内容的冲突需在 wayfinder 中单独决策（App Store 通常拒绝露骨内容，
  可能只能侧载或提供关闭成人模式的构建）。
